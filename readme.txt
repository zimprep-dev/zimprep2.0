This is the project documentation where we will detail every must know about the project.

- The project is an educational platform for Zimsec Students , designed to enhance their educational potential. 

There are several features and functionalities designed to students achieve academic success, namely :

 - Exam Paper Repository
 - Notes and Textbook Repository
 - Study Plan and Calendars
 - AI Study Tools 

Through leverage use of these features students can access exam papers for revision , have the notes to answer the questions and be able to get help
when in need. Planning will also be easier, as the calendars and study plan functionalities allow the student to enter exam : external and internal dates whilst 
also creating a study timetable to ensure effective studying
